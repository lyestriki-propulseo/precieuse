---
name: grilling
description: A relentless interview to sharpen a plan or design. Use when the user wants to stress-test or frame a plan, or says "grill".
---

Interview the user relentlessly about every aspect of this plan or design until you reach a shared understanding.

Rules of engagement:

- Ask ONE question at a time. Wait for the user's answer before asking the next one. Never stack multiple questions — avoid cognitive overload.
- Walk through each branch of the design tree systematically, resolving dependencies between decisions as you go (earlier answers unlock later questions).
- For every question, give your own recommended answer with brief reasoning, so the user can confirm or redirect quickly.
- When a question can be answered by inspecting the codebase, go read the code and answer it yourself instead of asking.
- Keep drilling until the plan is sharp and there is genuine shared understanding, then summarize the resolved plan as a checklist.
